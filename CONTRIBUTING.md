# Contributions and permissions

Thank you for supporting the Skyrim Legendary Edition modding community.

Runic Wheel LE is an independently developed, **source-available but proprietary** project. Its public availability does not permit copying, adapting, distributing or incorporating its code in other mods without a separate written license from Mhacks79.

## Reports welcome

Please open a well-scoped issue with:

- Skyrim LE version 1.9.32.0.8 and SKSE 1.7.3 confirmation;
- Runic Wheel build/version, KHA-OS version if relevant, and input device;
- reproducible steps, observed result and expected result;
- whether the issue reproduces without ENB, other native UI hooks or controller remappers;
- relevant logs and screenshots (with private information removed).

## Proposed code changes

**Do not assume that pull requests or source reuse are authorized.** Ask for permission before submitting patches, and discuss contribution/ownership terms in writing first. Submitting unsolicited source does not automatically change Runic Wheel's license or grant any license to third parties.

Please do not upload third-party SDKs, the game's executable, other mods' assets, copyrighted binaries or private reverse-engineering laboratory data.

## Scope

The main target is **TESV.exe 1.9.32.0.8 / SKSE LE 1.7.3 / MSVC-compatible x86 / D3D9**. An offset or ABI from SE/AE is **not** evidence that it is valid for LE. Maintain clear boundaries among hypothesis, static analysis, offline tests and in-game validation.
