# Original Runic Wheel LE artwork

- Frame, Unicode font atlas, and nameplate: original Runic Wheel LE assets retained from v0.15.
- v0.17 icons: newly generated original concept artwork created for this mod, resampled and mathematically clipped into 32 independent transparent tiles by `art/v017_heraldry.py`. No assets copied from Wheeler, Bethesda or other mods.
- Private source image stored as `art/V017-Heraldry-Source.png` for deterministic rebuild; icons distributed to game as a RWAT BGRA8 texture, not a runtime external dependency.
