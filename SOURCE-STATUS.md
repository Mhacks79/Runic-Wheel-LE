# Source publication status — Runic Wheel LE v0.25.1

The public repository currently includes its documentation, proprietary source-available notice and a subset of the original code. **It does not yet contain the entire v0.25.1 native implementation.**

The complete v0.25.1 original source tree has been curated into a separate upload package, including all the current C++ implementation, tests and original art resources, while excluding TESV.exe, compiled DLLs, private workstation files and Wheeler material.

To complete publication, an authorized contributor must push the remaining curated `v0251/` files through Git using the prepared source-upload package. After the push, check that `v0251/RunicWheelV011.cpp`, `v0251/RunicKhaosMenu.inl` and the full policy/test tree exist.

**Third-party interface headers** `KhaosAPI.h` and `KhaosThemeAPI.h` are excluded from the public upload pending redistribution-rights verification. Obtain those through the approved KHA-OS integration kit. SKSE LE SDK and TESV.exe are also external prerequisites.

No Wheeler source code, DLL or assets are part of this repository. The repository's original material is **source available / all rights reserved**.
