# Basic controls and wheel editor

Defaults may be changed through `RunicWheelLE.ini` or the optional KHA-OS panel.

## Gameplay

| Control | Default action |
|---|---|
| Middle mouse button | Open / close radial wheel |
| Mouse direction | Select a sector |
| Left click | Activate/equip in right hand where supported |
| Right click | Activate/equip in left hand where supported |
| Mouse wheel | Select next/previous item within a sector |
| Physical Q/E positions | Change wheel page (A/E on AZERTY) |
| Mouse side buttons | Alternate page navigation |

## Inventory and Magic

| Control | Default editor action |
|---|---|
| Hover item/spell, middle mouse | Open Runic Wheel |
| Left click | Add hovered entry to sector |
| Right click | Remove selected entry |
| Shift + left click | Move entry |
| Ctrl + left click | Copy entry |
| Shift + Alt + left click | Swap sector stacks |
| Shift + Ctrl + left click | Clone stack into empty sector |
| Shift + right click | Undo |
| Ctrl + right click | Redo |
| Alt + wheel | Reorder stack |

Some destructive actions require confirmation. Advanced help panels are limited to Inventory/Magic and may be disabled. Runic Wheel does **not** intercept reserved Skyrim F2–F5 keys; Tab must retain normal access to Skyrim menus.

## Optional hosted configuration

KHA-OS v0.5L exposes configuration of layout, appearance, labels, stacks, animation, input, gameplay and editor behavior. The wheel itself functions without KHA-OS.
